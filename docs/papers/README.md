# Papers

The papers describing ZisK are maintained in [zisk-papers](https://github.com/0xPolygonHermez/zisk-papers), and their published versions are on its [releases page](https://github.com/0xPolygonHermez/zisk-papers/releases):

- **ZisK Whitepaper**: the specification of the ZisK zkVM: the instruction set and its execution model, the arithmetization, the chips and buses, continuations, the recursive aggregation and the proving backend.
- **Security of ZisK**: the security analysis of ZisK's proof system, stating what an accepting proof guarantees and under which assumptions.
- **Secure Challenge Derivation in ZisK**: a short note on the lattice-based multiset hash (LtHash) behind ZisK's distributed challenge derivation.

Each release states the version of ZisK it describes.
