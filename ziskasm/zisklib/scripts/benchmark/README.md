# zisklib benchmarks and checks

These scripts measure and check the EF `zkvm_accelerators.h` functions
(`zkvm_*`) through the ziskasm C binding. Each script builds bare-metal C guests
and runs them on `ziskemu -X`.

## Requirements

- A RISC-V bare-metal C compiler, set in `RISCV_CC`: `riscv64-unknown-elf-gcc`
  (the default) or the xpack `riscv-none-elf-gcc`.
- A ziskemu built with the ziskasm feature. This is the default `ZISKEMU`:

  ```
  cargo build --release -p ziskemu --features ziskasm
  ```

- Python 3. The curve vectors also need `py_ecc`, and the KZG cases read the
  Ethereum trusted setup that ships with the `c-kzg` crate (found in
  `~/.cargo/registry`, or set `KZG_TRUSTED_SETUP`).

Scratch files go to `WORK` (default `/tmp/zisklib_bench`). `env.sh` holds these
settings.

## Benchmarks

Each benchmark gives the steps and variable cost of one call. `bench.sh` builds
`driver.c` with the call made once and three times, and halves the difference,
so the fixed costs cancel out (boot, the library's RAM image, the inputs).

| Script | Measures |
|---|---|
| `bench_accel.sh` | keccak256, keccak_f1600, sha256, ripemd160, blake2f, secp256k1 verify/ecrecover, secp256r1 verify, modexp at several sizes (inputs in `accel_inputs.c`) |
| `bench_curves.sh` | bn254 add/mul/pairing, BLS12-381 add/MSM/pairing/map, KZG point evaluation (seed-1 vectors from `curves_vec.py`) |
| `bench.sh NAME INPUTS.c 'CALL' ...` | any call, on any input file |
| `profile.sh INPUTS.c 'CALL' [N] [TOP]` | the steps of N calls, split by zisklib routine (`ziskemu -H` folded by `profile.py`, using the symbol map from `cargo run -p zisk-asm --example dump_syms`) |

To compare two builds, run a benchmark once per emulator:

```
./bench_curves.sh > new.txt
ZISKEMU=/path/to/other/ziskemu ./bench_curves.sh > old.txt
```

## Checks

Each check exits non-zero on a failure.

| Script | Checks |
|---|---|
| `check.sh [snap] [GUEST...]` | The example guests in `ziskasm/lang/c/example` and the edge-case guests in `guests/` (secp256k1, secp256r1, every hash length 0..420 at two alignments, the instructions that use the transpiler's scratch registers, every CSR instruction form, the memory and EVM extensions of `zkvm_mem.h` / `zkvm_evm.h`) against `gold/*.out`. `snap` rewrites the gold files; do that only after a change that is meant to alter the output. |
| `check_modexp.sh` | 202 zkvm_modexp cases against Python `pow`, generated by `modexp_vec.py` (moduli up to 64 bytes, edge cases) and `modexp_vec_long.py` (49..1025-byte moduli, odd and even) |
| `check_curves.sh [SEED...]` | 103 bn254 / BLS12-381 / KZG cases per seed (default seeds 1, 2, 3) from `curves_vec.py`, including valid KZG proofs, batches of more than 8 pairs, and points outside the subgroup. The guest compares each result with `py_ecc`, and also hashes every status and output into a transcript. With `REF_ZISKEMU` set to an emulator built from another commit, the two transcripts must also match, which covers the cases that have no `py_ecc` result. |
