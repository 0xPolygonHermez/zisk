# zisk-contracts

Solidity verifier contracts for the Zisk zkVM, one directory per hash family
(`poseidon1/`, `poseidon2/`, `blake3/`): `ZiskVerifier.sol` on top of the family's
pilfflonk verifier, `PilfflonkVerifier.sol`. They are generated by the family's setup
and installed by `tools/release-artifacts/regen.sh`; do not edit them by hand.

A Hardhat test submits a blake3 pilfflonk proof (`test/blake3_pilfflonk.bin`) on-chain.

## Running the verifier test

All commands below are run from this directory:

```bash
cd zisk-contracts
```

Export the four ABI fields the on-chain verifier expects. The subcommand is
developer-facing, so it lives in `cargo-zisk-dev` rather than `cargo zisk`:

```bash
cargo build --release -p cargo-zisk --bin cargo-zisk-dev
../target/release/cargo-zisk-dev export-solidity-calldata -p test/blake3_pilfflonk.bin -o fixtures/blake3.json
```

Install Hardhat deps (first run only) and run the test:

```bash
npm install
ZISK_SOLIDITY_FIXTURE=fixtures/blake3.json \
  ZISK_SOLIDITY_CONTRACT=blake3/ZiskVerifier.sol:ZiskVerifier npx hardhat test
```
